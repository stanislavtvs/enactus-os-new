# Статус

**Фаза 1.** Каркас Django, глобальная модель пользователя, вход и выход по сессии, healthcheck API и локальный Compose с PostgreSQL 16.

**Первый инкремент фазы 2.** Организации, владелец и активное членство создателя. Добавлены API списка, создания и чтения, а также веб-страницы выбора и просмотра организации. Создание доступно по разрешению Django. Чтение ограничено активным членством.

**Следующий инкремент фазы 2.** Настраиваемая политика создания организаций, приглашения и заявки на вступление.
