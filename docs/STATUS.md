# Статус

Фаза 1 вводит каркас Django, глобальную модель пользователя, вход и выход по сессии, healthcheck API и локальный Compose с PostgreSQL 16.

Фаза 2 добавит организации, владельца и членства, политику создания, приглашения и заявки на вступление. Первый API и интерфейс выбора организации будут проверены на доступ из чужой организации.
