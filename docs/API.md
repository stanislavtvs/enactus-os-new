# API

| Метод | Маршрут | Доступ и ответ |
|---|---|---|
| GET | `/api/v1/health/` | Публичный. HTTP 200 и JSON `{"status":"ok"}`. Проверяет HTTP-процесс, доступность БД проверяет Compose. |
| GET | `/api/v1/openapi.json` | Схема API в режиме разработки. |
| GET | `/api/v1/docs` | Swagger UI в режиме разработки. |

Вход через Django `GET/POST /accounts/login/`, выход через `POST /accounts/logout/`. Формы защищены CSRF. Главная страница `/` доступна после входа.

## Организации

| Метод | Маршрут | Успешный ответ |
|---|---|---|
| GET | `/api/v1/organizations/` | HTTP 200, массив доступных организаций в порядке возрастания идентификатора. |
| POST | `/api/v1/organizations/` | HTTP 201, созданная организация. Создателю присваиваются владение и активное членство. |
| GET | `/api/v1/organizations/{id}/` | HTTP 200, организация с указанным целочисленным идентификатором. |

Объект организации содержит целочисленный `id`, строку `name` и время создания `created_at` в ISO 8601. Для создания передайте JSON вида `{"name":"Enactus Toraighyrov"}`. Пробелы по краям удаляются, длина названия должна составлять от 1 до 200 символов. Нулевой символ NUL отклоняется. Ошибка проверки тела запроса возвращает HTTP 422.

Для чтения требуются сессия Django и активное членство. Запрос конкретной организации без активного членства возвращает HTTP 404, как и запрос отсутствующего идентификатора. Правило действует и для суперпользователя.

Для создания требуются сессия Django, CSRF-токен в заголовке `X-CSRFToken` и разрешение `organizations.add_organization`. Анонимный GET и анонимный POST с действительным CSRF-токеном возвращают HTTP 401. POST без действительного CSRF-токена или без разрешения на создание возвращает HTTP 403.

Веб-страницы `/organizations/` и `/organizations/{id}/` используют те же правила чтения. Анонимного посетителя перенаправляют на страницу входа.
