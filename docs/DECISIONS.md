# Решения

- **Глобальная учётная запись.** `accounts.User` наследует Django `AbstractUser` и подключается до первой миграции. Для входа используется уникальный username. Связь аккаунта с организацией хранится в `OrganizationMembership`.
- **Изоляция локальной среды.** Compose-проект `enactus_os_next_dev` использует собственный том PostgreSQL 16. Порт БД доступен в сети Compose. Веб-порт привязан к loopback.
- **Сессии браузера.** Используются стандартные представления Django, CSRF и HttpOnly сессионная cookie. При выключенном DEBUG cookies сессии и CSRF требуют HTTPS.
- **Время.** Настройки Django используют UTC. Локальный часовой пояс будет задаваться организацией при реализации календаря.
- **Владение и членство.** У организации один владелец. Создание организации и активного членства владельца выполняется в одной транзакции. Пара «аккаунт и организация» уникальна.
- **Границы доступа.** API и серверные страницы используют одну выборку по активному членству. Для создания действует глобальное разрешение `organizations.add_organization`.
- **Правила вступления.** Владелец выбирает `invites`, `requests` или `both`. Значение по умолчанию — `invites`. Владелец с активным членством может делегировать управление участниками конкретной организации. При выдаче приглашения, принятии приглашения, подаче и одобрении заявки проверяются действующие правила вступления.
- **Ссылки.** Приглашение привязано к аккаунту получателя и действует 7 дней. База хранит SHA-256 от случайного токена. Ссылка передаёт токен во фрагменте URL, который браузер удаляет из адресной строки после считывания. Пользователь может ответить из личного списка приглашений. Ссылка на подачу заявки содержит идентификатор организации с подписью Django.
- **Согласованность.** При создании или активации членства и при изменении правил вступления сервис блокирует строку организации внутри транзакции. Для каждой пары «организация и аккаунт» разрешено по одному приглашению и одной заявке в статусе `pending`. Повторная активация членства сбрасывает ранее выданное право управления.
