# Enactus OS — Codex Fresh Start (пакет требований)

Это **НЕ готовая Django-платформа**, а полный комплект инструкций, из которого Codex создаст **новую** платформу с нуля.

Содержимое:

- `docs/TECHNICAL_SPEC.md` — полное техническое задание (MVP и последующие версии, БД/API/UI/безопасность/тесты).
- `AGENTS.md` — обязательные инструкции координатору Codex.
- `docs/AGENT_ROLES.md` — распределение работ и правила субагентов.
- `.codex/agents/*.toml` — project-scoped определения специалистов Codex.
- `.codex/config.toml` — ограничение одновременного числа агентов для этой папки.
- `START_HERE.md` — точные инструкции для старта и готовый первый запрос.

**Использовать в новом каталоге, не в старом `enactusos`.** После распаковки прочитать `START_HERE.md`.
